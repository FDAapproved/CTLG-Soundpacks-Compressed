# CC-Sounds
A continuation of the `CO.AG soundpack` initiated by **SkyBreach**.
This version aims to provide a quality soundpack using CC0 or CC-BY ressources with proper attribution.

## Download
Download the source code for this repository using the '<> code' widget, on desktop. This repository and it's parent lack .zip releases as of writing; the installation section will walk you through what files you should keep. 

## Installation
- Open your C:TLG root folder,
- Navigate to the `/sounds/` sub-directory,
- Copy the project folder `/CC-Sounds/` from this repository into `/sounds/`,
- When you're finished, you should have a subdirectory named `/CC-Sounds/` inside of `/sounds/`,
- Start the game, navigate to the sound options, and select `'CC-Sounds'`,
This fork's files will override the builtin CC-Sounds, and you'll be able to hear compressed versions of them upon restarting the game.
